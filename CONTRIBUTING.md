# Contribuir

Gracias por ayudar a que esta plantilla sea fácil de usar.

1. Crea un fork y una rama descriptiva.
2. Instala con Node.js 22.18+ o 24+ y `npm ci`.
3. Lee AGENTS.md; si trabajas con un agente, debe consultar la documentación de la versión instalada de Next.js.
4. Mantén los ejemplos pequeños, los textos en español y las claves fuera del código.
5. Actualiza README, .env.example y la guía integrada si cambia el recorrido de uso.
6. Usa `npm run format` para dar formato al código y la documentación. Ejecuta `npm run check`, `npm run build` y `npm run test:integration`.
7. Abre un pull request con el problema, el comportamiento resultante y las comprobaciones realizadas.

Para reportar un error, incluye pasos reproducibles, versión de Node.js y mensaje de error, sin secretos ni datos privados. Para añadir un proveedor MCP, usa la configuración genérica de URLs y headers; evita integraciones ocultas que se activen sin selección del usuario.
